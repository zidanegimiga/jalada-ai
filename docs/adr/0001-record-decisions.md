# 0001. Record architecture decisions

Status: Accepted
Date: 2026-10-09

## Context
I want a clear record of why each choice was made. Decisions made in chat or in code comments get lost.

## Decision
Every choice of library, service, data store or design pattern gets a short decision record in this folder, using `0000-template.md`, before it lands in code.

## Consequences
- A little writing before each decision.
- Anyone reading the code later can see why things are the way they are.
